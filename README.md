# PromptVault

A responsive, searchable AI image prompt gallery with visual references and one-click copying.

## Features
- Search prompt titles, descriptions, styles, models, and prompt text
- Filter by creative category
- Copy full prompts with one click
- Responsive dark interface
- Static site; no build step or API key required

## Current collection
The launch version contains 12 original starter prompts. They are clearly presented as original inspiration examples, not falsely attributed to outside creators. External visual references are used as mood previews; they are not claimed to be outputs generated from the exact prompt.

## Run locally
Open `index.html` in a browser.

## Deploy
The included GitHub Actions workflow deploys the site to GitHub Pages when Pages is enabled for this repository (Settings → Pages → Build and deployment → GitHub Actions).

## Contribute
Add prompt objects to `prompts.js`. Keep source attribution accurate when adding prompts from other creators, and only use preview images you have permission to display.
